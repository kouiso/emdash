# rag-chat サンプルの概要

このサンプルは RAG（Retrieval-Augmented Generation、検索拡張生成）の最小構成です。
質問を受け取ると、まず docs フォルダの Markdown から関係がありそうな段落を探し、
見つけた段落だけを Claude に渡して答えてもらいます。

モデルに全部の資料を渡さず、関係する部分だけを渡すのが RAG の考え方です。
渡す文字数が減るので、1 回あたりの料金と待ち時間も小さくなります。

## 処理の流れ

1. docs フォルダの Markdown ファイルを読み込む
2. 見出しと空行を境目にして、小さなチャンク（断片）に分ける
3. 質問とチャンクを BM25 という式で点数づけする
4. 点数の高い上位 k 件を取り出す
5. 取り出したチャンクを根拠として Claude に質問する
