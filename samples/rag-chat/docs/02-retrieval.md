# 検索の仕組み（BM25）

このサンプルの検索は外部サービスを使わず、TypeScript だけで動きます。
API キーがなくても、オフラインで検索結果を確認できます。

## トークン化

文章を「トークン」という単位に分けます。英数字は単語ごとに区切り、小文字にそろえます。
日本語は単語の間に空白がないため、隣り合う 2 文字を 1 組にした「文字 bigram」を使います。
たとえば「検索拡張」は「検索」「索拡」「拡張」の 3 つになります。

## BM25 の点数

BM25 は、質問に出てくるトークンがチャンクに何回出てくるかで点数を決めます。
どの文書にも出てくるありふれたトークンは点数を低く、珍しいトークンは高くします。
長すぎるチャンクが有利になりすぎないよう、長さで補正もかけます。

パラメータ k1 は出現回数の効き方、b は長さ補正の強さを決めます。
このサンプルでは一般的な値の k1 = 1.2、b = 0.75 を使っています。

## 埋め込みベクトルとの違い

本番の RAG では、文章を数値のベクトルに変える埋め込みモデルを使うことが多いです。
BM25 は言い換え（同じ意味の別の言葉）に弱い一方、キーが不要で結果の理由を説明しやすい利点があります。
