# rag-chat: いちばん小さい RAG チャットのサンプル

手元の Markdown から質問に関係する段落を探し、その段落だけを根拠にして Claude に答えさせる TypeScript のサンプルです。

```
質問 ──▶ docs/*.md を読む ──▶ チャンクに分ける ──▶ BM25 で点数づけ ──▶ 上位 k 件
                                                                         │
                                         回答 ◀── Claude (Anthropic SDK) ◀┘
```

- 検索（BM25）は TypeScript だけで書いてあり、外部サービスも API キーも使いません。オフラインで動きます。
- `ANTHROPIC_API_KEY` が無いときは、Claude に渡す予定のコンテキストを表示して終了コード 0 で終わります。検索がうまく動いているかをお金をかけずに確かめられます。
- 同梱の `docs/` には、このサンプル自身の説明を書いた短い Markdown が 3 本入っています。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `src/chunk.ts` | Markdown を見出しと空行で区切り、400 文字以内のチャンクにまとめる |
| `src/bm25.ts` | トークン化（英数字は単語、日本語は 2 文字ずつの bigram）と BM25 検索 |
| `src/loadDocs.ts` | フォルダ内の `.md` を読んでチャンクにする |
| `src/answer.ts` | 取り出したチャンクを `<chunk>` タグで包み、`messages.create` で Claude に送る |
| `src/cli.ts` | コマンドの入口。環境変数を読み、検索結果と回答を表示する |
| `test/*.test.ts` | チャンク分割・検索のテストと、SDK をネットワークなしで呼ぶテスト |

## 必要なもの

- Node.js 22.18 以上（TypeScript をビルドせずに `node src/cli.ts` で直接実行します。型を取り除いて実行する機能が既定で有効になったのが 22.18.0 からなので、それより古い 22.x では `.ts` を読めずに止まります。23 系なら 23.6.0 以上です。`package.json` の `engines` も同じ範囲にしてあり、古い版で `npm ci` すると `EBADENGINE` の警告が出ます。動作確認は v22.22.0）
- Claude に答えさせる場合だけ Claude API のキー（[Claude Console](https://platform.claude.com/) で発行）

## セットアップ

リポジトリから取った場合は `samples/rag-chat`、zip で受け取った場合は展開してできた `rag-chat` フォルダに移動してから実行します。

```bash
cd samples/rag-chat   # zip の場合は cd rag-chat
npm ci          # package-lock.json どおりに入れる（@anthropic-ai/sdk 1.3.0 など）
```

## 実行コマンド

```bash
npm run typecheck                 # tsc --noEmit で型チェック
npm test                          # node:test でテスト
npm start                         # 既定の質問で実行
npm start -- "RAG_TOP_K の既定値は？"   # 質問を指定して実行
```

Claude に答えさせる場合は、キーを環境変数で渡します（キーをファイルに書いてコミットしないでください）。

```bash
export ANTHROPIC_API_KEY="（自分のキー）"
npm start -- "日本語の文章はどうやって検索していますか？"
```

### 環境変数

| 名前 | 既定値 | 説明 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | なし | 未設定なら検索結果だけ表示して終了 |
| `ANTHROPIC_MODEL` | `claude-sonnet-5-5` | 使うモデル ID |
| `RAG_TOP_K` | `3` | Claude に渡すチャンク数（1 以上の整数） |
| `RAG_DOCS_DIR` | `docs/` | 読み込む Markdown フォルダ |

`.env.example` は変数の一覧です。このサンプルは `.env` を自動では読み込みません。

## 1 回あたりの料金の目安

**2026-10-31 時点**で [公式の料金ページ](https://platform.claude.com/docs/en/about-claude/pricing) に載っていた Claude Sonnet 5.5 の料金は、入力 100 万トークンあたり $2、出力 100 万トークンあたり $10 でした。料金は変わることがあるので、使う前に必ず公式ページで確認し直してください。

このサンプルの 1 回の質問では、入力はシステム指示・チャンク 3 件・質問を合わせて 1,000〜2,000 トークン程度です。出力の上限は `max_tokens: 16000`（`src/answer.ts` の `MAX_TOKENS`）にしています。Sonnet 5.5 は既定で思考し、思考を切る設定（`thinking: {type: "disabled"}`）は 400 エラーになります。思考の分も `max_tokens` と出力トークンに数えられるので、上限を小さくすると思考だけで使い切って回答が途中で切れたり空になったりします（[公式ドキュメント](https://platform.claude.com/docs/en/build-with-claude/thinking)、2026-10-31 参照）。料金がかかるのは実際に出力したトークンだけで、上限を上げただけでは増えません。

```
入力   2,000 トークン × $2  / 1,000,000 = $0.004
出力  16,000 トークン × $10 / 1,000,000 = $0.16
合計  上限まで使い切った場合でおよそ $0.164 / 回
```

これは上限まで使い切ったときの見積もりです。実際の値は実行後に表示される `使用トークン` で計算してください。`RAG_TOP_K` を増やしたり大きな資料を使ったりすると入力トークンが増えます。

## 制限

- **言い換えに弱い**: BM25 は同じ文字が出てくるかどうかで点数をつけるので、「料金」と「価格」のような別の言葉は一致しません。本番では埋め込みモデル（ベクトル検索）との併用を検討してください。
- **日本語のトークン化は簡易版**: 2 文字の bigram なので、関係の薄いチャンクにも小さな点数がつきます（例: 上の出力の 3 件目）。形態素解析は使っていません。
- **毎回すべて読み直す**: インデックスを保存しないため、実行のたびに全ファイルを読み直します。数百ファイル程度までを想定しています。
- **会話の履歴を持たない**: 1 回の実行で 1 問だけ答えます。続けて質問しても前の質問は覚えていません。
- **ストリーミングしない**: 回答は全部できあがってから表示します。
- **Markdown の構文はほぼそのまま**: 表やコードブロックも普通の文章としてチャンクに入ります。
- **回答の正しさは保証しない**: 資料だけで答えるように指示していますが、モデルが資料にないことを言う可能性はゼロではありません。表示される `source` を見て元の段落を確認してください。
