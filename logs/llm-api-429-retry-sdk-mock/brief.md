## 上位記事を見たか

2026-10-31 に WebSearch で「Claude API 529 overloaded 429 リトライ TypeScript」を検索し、結果のタイトルと要約だけを見た（本文は開いていない）。上位は Microsoft Dev Proxy のドキュメント「Anthropic 529 overloaded_error」の多言語版と、ポルトガル語のブログ記事で、日本語の記事は出てこなかった。要約では、529 と 429 の違い、SDK の `maxRetries`、自前のリトライと SDK のリトライが重なる注意が挙がっていた。この検索語は CSV の行ではなく、上位記事の傾向を見るために使っただけ。

差別化の判断: SDK 1.3.0 のソース（`src/client.ts`）を読んだうえで、モックサーバーで実際に回数と間隔を測った結果を載せる。自前のループで包むと 9回送ること、`retry-after` の無い月の利用上限の 429、`retry-after` が長いと SDK がその秒数だけ待ち続けること（`signal` で区切る）を入れる。
