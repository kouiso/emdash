## 態度（guides/03 不在1）

zod のスキーマを1回だけ書き、ツール定義と入力の検証の両方に使う。ツールの入力はモデルが作る「入力側」の値なので、`io: "input"` を選ぶ。SDK の `betaZodTool` は `io` を指定しないので、`.default()` の項目が必須になる点は自分で確かめたうえで書く。

## 読み終えた人ができるようになること

自分の zod のスキーマから、Claude API のツール定義に入れる `input_schema` を作り、SDK の型で確かめ、返ってきた入力を同じスキーマで検証できる。`io` と strict の制約を見て、どちらの書き方にするか選べる。
